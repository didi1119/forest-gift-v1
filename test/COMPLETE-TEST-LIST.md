## 📋 測試分類明細

### 1. Basic（基礎功能）- 2 個測試

#### 1.1 基礎連線測試
- **目的**: 驗證 Google Apps Script API 連線
- **檢查項目**:
  - 能否連接到 Google Sheets
  - 能否讀取 Partners、Bookings、Payouts 數據
- **預估時間**: 5秒

#### 1.2 數據結構驗證
- **目的**: 驗證 Partners 表結構完整性
- **檢查項目**:
  - Partners 表至少有一筆資料
  - 必要欄位存在（partner_code, partner_name, available_points）
- **預估時間**: 10秒

---

### 2. Commission（佣金計算）- 2 個測試

#### 2.1 LV1 住宿金佣金計算
- **目的**: 驗證 LV1 大使住宿金佣金計算
- **檢查項目**:
  - 找到 LV1 + ACCOMMODATION 大使
  - 基礎佣金應為 1000 點
- **預估時間**: 10秒
- **可能跳過**: 如果找不到符合條件的大使

#### 2.2 LV1 首次推薦獎勵驗證
- **目的**: 驗證首次推薦獎勵邏輯
- **檢查項目**:
  - 找到 successful_referrals = 0 的 LV1 大使
  - 首次推薦應獲得 2500 點（1000 + 1500）
- **預估時間**: 10秒
- **可能跳過**: 如果找不到新大使

---

### 3. Lifecycle（訂房生命週期）- 1 個測試

#### 3.1 訂房完整生命週期測試
- **目的**: 測試從創建到確認的完整流程
- **測試步驟**:
  1. 創建測試訂房（room_price: 5000）
  2. 驗證初始狀態（PENDING）
  3. 確認入住
  4. 驗證佣金計算（含首次推薦獎勵判斷）
  5. 驗證狀態更新（COMPLETED, CALCULATED）
- **檢查項目**:
  - stay_status: PENDING → COMPLETED
  - commission_status: PENDING → CALCULATED
  - 佣金金額正確（根據等級和首次推薦）
- **預估時間**: 35-40秒

---

### 4. Cancellation（取消與回滾）- 3 個測試

#### 4.1 佣金撤銷與恢復完整循環測試
- **目的**: 測試複雜的取消和恢復場景
- **測試步驟**:
  1. 創建 3 筆訂房
  2. 確認所有訂房入住
  3. 驗證佣金累積
  4. 取消第 2 筆訂房
  5. 驗證佣金撤銷
  6. 創建新訂房並確認
  7. 最終數據驗證
- **檢查項目**:
  - 點數正確累積和撤銷
  - Payouts 表有 COMMISSION_REVERSAL 記錄
  - 數據一致性
- **預估時間**: 90-120秒

#### 4.2 簡單取消測試
- **目的**: 測試基本的取消和撤銷
- **測試步驟**:
  1. 記錄初始點數
  2. 創建並確認訂房
  3. 驗證點數增加
  4. 取消訂房
  5. 驗證點數回滾
- **檢查項目**:
  - 點數增加正確
  - 點數撤銷正確
  - 撤銷金額等於原佣金
- **預估時間**: 30-40秒

#### 4.3 使用住宿金後取消訂房測試
- **目的**: 測試住宿金使用後的取消流程
- **測試步驟**:
  1. 記錄初始點數
  2. 使用住宿金 1000 點
  3. 驗證點數扣除
  4. 查找 Accommodation_Usage 記錄
  5. 嘗試取消住宿金使用
- **檢查項目**:
  - available_points 正確扣除
  - points_used 正確增加
  - 取消功能（可能缺少 API）
- **預估時間**: 20-30秒
- **可能跳過**: 缺少 cancel_accommodation_usage API

---

### 5. Points（點數操作）- 1 個測試

#### 5.1 點數轉現金測試
- **目的**: 測試住宿金轉換為現金
- **測試步驟**:
  1. 記錄轉換前狀態
  2. 轉換 2000 點住宿金
  3. 驗證轉換後狀態
- **檢查項目**:
  - available_points 減少 2000
  - pending_commission 增加 1000（2:1 比例）
- **預估時間**: 20-25秒
- **前置條件**: 大使至少有 2000 點

---

### 6. Level（等級判定）- 1 個測試

#### 6.1 等級判定邏輯測試
- **目的**: 驗證等級分佈統計
- **檢查項目**:
  - 統計 LV1 大使數量
  - 統計 LV2 大使數量
  - 統計 LV3 大使數量
- **預估時間**: 5-10秒

---

### 7. Consistency（數據一致性）- 2 個測試

#### 7.1 住宿金點數一致性驗證
- **目的**: 驗證 Partners 點數與 Payouts 記錄一致
- **檢查項目**:
  - 對每個大使計算 Payouts 記錄的點數總和
  - 比對 Partners.available_points
  - 找出不一致的大使
- **驗證公式**:
  ```
  expected_points =
    Σ(ACCOMMODATION payouts)
    - Σ(POINTS_ADJUSTMENT_DEBIT payouts)
    - Σ(CASH_CONVERSION points_used)
    - Σ(COMMISSION_REVERSAL where type=ACCOMMODATION)
  ```
- **預估時間**: 10-15秒
- **重要性**: 🚨 高（檢測數據完整性問題）

#### 7.2 Payouts 審計完整性驗證
- **目的**: 驗證 Payouts 表記錄完整性
- **檢查項目**:
  - Payouts 表結構正確
  - 必要欄位存在
  - 記錄數量合理
- **預估時間**: 5-10秒
