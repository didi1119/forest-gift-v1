# Google Analytics 4 設定指南

## 建立 GA4 Property

### 步驟 1：建立帳戶

1. 前往 [Google Analytics](https://analytics.google.com)
2. 點擊左下角「管理」→「建立帳戶」
3. 帳戶名稱：`靜謐森林知音計畫`
4. 資料共用設定：建議全部勾選

### 步驟 2：建立 Property

1. 資源名稱：`靜謐森林知音計畫`
2. 時區：`台灣`
3. 貨幣：`台灣新台幣 (TWD)`

### 步驟 3：業務資訊

- 業務類別：`旅遊與交通`
- 業務規模：`小型 (1-10 名員工)`
- 用途：檢視客戶行為報表、評估廣告成效

### 步驟 4：設定資料串流

1. 平台選擇「網站」
2. 輸入網站 URL（部署後的實際網址）
3. 串流名稱：`靜謐森林主網站`
4. 建立串流後取得 **Measurement ID**（格式：`G-ABC123DEF4`）

> 如果還沒有部署，可先填 `https://example.com`，部署後在「管理」→「資料串流」更改。

### 步驟 5：更新設定

將 Measurement ID 更新到 `js/config.js` 中的 `GA4_MEASUREMENT_ID`。

---

## 設定自訂維度

1. 左側選單「管理」→「自訂定義」→「建立自訂維度」
2. 填入：
   - 維度名稱：`推薦來源`
   - 範圍：`事件`
   - 事件參數：`subid`
   - 說明：`夥伴推薦代碼追蹤`
3. 儲存

## 設定轉換事件

建議將以下事件設為轉換：

| 事件名稱 | 說明 |
|---------|------|
| `card_draw` | 抽卡互動 |
| `journal_submit` | 週記提交 |
| `line_click` | LINE 優惠券點擊 |
| `booking_intent` | 訂房意圖 |

## 測試驗證

### 即時報表測試

1. GA4 →「報表」→「即時」
2. 開啟網站進行操作（抽卡、播放音樂等）
3. 確認即時報表顯示活動

### subid 追蹤測試

1. 使用 `?subid=TEST123` 進入網站
2. 進行互動操作
3. 檢查事件是否包含 `subid` 參數

---

## 暫時不設定 GA4

網站在沒有 GA4 的情況下仍可正常運作。追蹤事件會在瀏覽器 Console 中顯示：

1. 開啟網站
2. F12 → Console
3. 進行互動，會看到追蹤訊息

準備好時再按照上述步驟設定即可。
