🧪 測試步驟

  1. 填寫推薦人代碼和專屬 LINE 優惠券連結
  2. 點擊「生成測試連結」
  3. 點擊「🧪 測試此連結」打開主頁連結
  4. 打開瀏覽器的開發者工具（F12），查看 Console
  5. 應該會看到：🎁 已載入專屬優惠券連結: https://lin.ee/xxxxx
  6. 點擊主頁上的「領取專屬森林優惠 🎁」按鈕
  7. 檢查 Console，應該會看到使用了正確的專屬優惠券連結
  8. 確認跳轉到了正確的 LINE 優惠券頁面

✅ 預期結果

  • ✓ 主頁載入時，Console 顯示「已載入專屬優惠券連結」
  • ✓ 優惠券按鈕下方顯示「✓ 已載入專屬優惠券連結」
  • ✓ 點擊按鈕後，Console 顯示使用「專屬優惠券連結（帶追蹤）」
  • ✓ 最終跳轉到正確的 LINE 優惠券頁面
  • ✓ Google Sheets 的 Clicks 表格記錄了點擊

⚠️ 故障排除

問題：Console 沒有顯示優惠券連結

→ 檢查 URL 是否包含 coupon_url 參數

問題：點擊按鈕後跳轉到預設 LINE

→ 確認 Apps Script 的 handleRedirect 函數正確傳遞了 coupon_url

問題：短網址無法生成

→ 檢查網路連線，或使用完整連結測試
